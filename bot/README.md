# Telegram-бот «ХайпОтвет»

Бот работает на чистом Node.js (без `npm install` и сторонних библиотек):
- принимает предложенные вопросы от читателей и пересылает их вам в Telegram;
- позволяет отвечать пользователю прямо через **Reply** на пересланное сообщение;
- ищет готовые ответы по всей базе сайта (717 вопросов) и выдаёт случайный разбор;
- сохраняет все присланные вопросы в `bot/suggestions.json`.

## Как запустить локально
1. Откройте терминал в папке проекта и запустите:
   ```powershell
   node bot/bot.mjs
   ```
2. В консоли появится команда вида `/setadmin xxxxxx` — отправьте её вашему боту в Telegram, чтобы привязать себя как администратора.
3. После этого все вопросы от людей будут приходить прямо к вам в личку.

## Как запустить 24/7 на сервере (VPS)
1. Скопируйте проект на VPS (Ubuntu + Node.js 18+), убедитесь, что файл `bot/.env` заполнен.
2. Запустите через `systemd` или `pm2`:
   ```bash
   pm2 start bot/bot.mjs --name hypeotvet-bot
   pm2 save
   ```

> Никогда не загружайте `bot/.env` в публичный репозиторий GitHub — он уже добавлен в `.gitignore`.

# ХайпОтвет

Справочник коротких пошаговых ответов на вопросы, которые чаще всего ищут после Reels, TikTok и Shorts: ремонт, сантехника и быт, ЖКХ и Госуслуги, смартфоны и iCloud, авто, права, аренда, путешествия, медицина по ОМС, игры и Steam, приложения и нейросети.

- **Живой сайт:** https://hypeotvet.netlify.app/
- **Telegram-бот (поиск, шпаргалки, предложка, `/status`):** https://t.me/HypeOtvet_app

## Что внутри
- **30 категорий** и **1 017 уникальных разборов** (`data.js` + `data/pack-01.js` – `data/pack-18.js`).
- **Статический SEO-генератор** (`build-seo.mjs`): собирает в `dist/` пререндеренную главную страницу, 30 страниц разделов, 1 017 отдельных HTML-страниц с `FAQPage` и `BreadcrumbList` JSON-LD, `sitemap.xml`, `robots.txt` и `netlify.toml`.
- **Интерактив без бэкенда:** умный поиск с исправлением раскладки и синонимами, закладки («Сохранённое»), ночная/светлая тема, копирование кода, 5 калькуляторов/чек-листов и генератор PNG-карточек `1080 × 1350` для сторис.
- **Telegram-бот** (`bot/bot.mjs`): Deep Linking (`?start=q_<id>`), команда `/status` (`bot/status.txt`), подписка на обновления и предложка вопросов.

## Быстрый старт
```powershell
# Собрать статическую SEO-версию в dist/
node build-seo.mjs

# Запустить Telegram-бота (нужен bot/.env по образцу bot/.env.example)
node bot/bot.mjs
```

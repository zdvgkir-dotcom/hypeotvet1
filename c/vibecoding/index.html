Раздел 19

Вайбкодинг бесплатно

Как делать приложения и сайты, почти не умея кодить. 30 вопросов.

  • Что такое вайбкодинг простыми словами?

    Это когда вы описываете приложение словами, а нейросеть пишет код. Вы проверяете результат и просите исправить — почти не трогая код руками.

    Хайп1 мин чтения
  • Какие инструменты для вайбкодинга можно использовать бесплатно?

    Бесплатно: Trae, Qwen Code, VS Code + Cline/Continue с бесплатными моделями, а также пробные тарифы Cursor, Windsurf, Bolt и Lovable.

    Хайп1 мин чтения
  • Как сделать первый проект вайбкодингом за вечер?

    Выберите маленькую идею, опишите её подробно в одном промпте, работайте мелкими шагами и сохраняйте рабочие версии через Git.

    Новое1 мин чтения
  • Какие ошибки совершают новички в вайбкодинге?

    Слишком большие запросы, нет Git, ключи API прямо в коде, слепое доверие ИИ и попытки сделать «убийцу Instagram» с первого раза.

    1 мин чтения
  • Нужно ли учить программирование, если есть вайбкодинг?

    Для простых проектов — нет. Для серьёзных продуктов и работы в IT — да: базовое понимание кода, Git и устройства веба резко повышает результат.

    1 мин чтения
  • Как составить ТЗ и план (PRD) перед стартом вайбкодинга?

    Опишите в одном файле PRD.md цель продукта, 3-5 главных экранов, модель данных и список ограничений. Попросите ИИ сначала разбить этот документ на этапы, и только потом писать код.

    Хайп1 мин чтения
  • Зачем нужны файлы .cursorrules, AGENTS.md и CLAUDE.md для ИИ?

    Это постоянные инструкции в корне проекта, которые AI-редактор автоматически подгружает в каждый чат. Они фиксируют стек, стиль кода, команды запуска и запреты, чтобы не повторять их вручную.

    Новое1 мин чтения
  • Как подключить базу данных к проекту вайбкодингом (SQLite, Supabase, PocketBase)?

    Для прототипа и небольшого сервера берите SQLite или PocketBase — они хранятся в одном файле без сложной настройки. Для веб-сервиса с облачным PostgreSQL и готовым API подойдёт Supabase.

    1 мин чтения
  • Как сделать авторизацию пользователей вайбкодингом без дыр в безопасности?

    Не просите ИИ изобретать криптографию с нуля: используйте проверенные библиотеки (Auth.js, Lucia, Better Auth, Supabase Auth или встроенную авторизацию PocketBase) и храните пароли только в виде хэшей bcrypt или Argon2.

    1 мин чтения
  • Как правильно хранить API-ключи в .env и не слить их на GitHub?

    Храните все секреты в файле .env, сразу добавьте .env в .gitignore и никогда не передавайте приватные ключи во фронтенд-код браузера. В репозиторий кладите только шаблон .env.example с пустыми значениями.

    Хайп1 мин чтения
  • Как выложить проект из вайбкодинга в интернет за 5 минут?

    Статичный сайт бесплатно публикуется на GitHub Pages, Cloudflare Pages или Netlify прямо из репозитория. Для проекта с бэкендом и базой данных используйте Timeweb Cloud App Platform, Amvera или недорогой VPS в РФ.

    1 мин чтения
  • Как чинить ошибки в вайбкодинге с помощью консоли браузера (F12)?

    Нажмите F12, откройте вкладки Console и Network, воспроизведите баг и скопируйте точный красный текст ошибки вместе с кодом ответа сервера в чат с ИИ. Это решает 80% проблем с первого раза.

    1 мин чтения
  • Как сделать мобильное приложение вайбкодингом: PWA, Capacitor или React Native?

    Для быстрого запуска без модерации сторов делайте PWA. Если нужен файл для RuStore, Google Play или App Store из готового веб-проекта — оберните его в Capacitor. Для сложной анимации и нативного UI берите React Native (Expo).

    Хайп1 мин чтения
  • Как экономить токены и лимиты в AI-редакторах кода?

    Указывайте конкретные файлы вместо сканирования всего проекта, начинайте новый чат под каждую задачу, исключайте тяжёлые папки в .cursorignore и отдавайте рутинные правки более лёгким и дешёвым моделям.

    1 мин чтения
  • Как работать с Git в вайбкодинге и откатывать неудачные правки ИИ?

    Делайте коммит перед каждым крупным запросом к ИИ. Если агент сломал проект, одной командой git checkout -- . или git reset --hard HEAD вы мгновенно вернётесь к последней рабочей версии.

    1 мин чтения
  • Как просить ИИ писать тесты и проверять свой же код?

    Просите писать тесты по конкретным бизнес-сценариям и крайним случаям (пустой ввод, ошибки сети, отрицательные числа) и обязательно запускайте их в терминале. Для критичной логики проверяйте, что тест падает, если намеренно сломать функцию.

    1 мин чтения
  • Когда лучше начать новый чат с ИИ, а не продолжать старый?

    Открывайте новый чат, как только завершили текущую фичу, сменили тему или заметили, что ИИ начал ходить по кругу и повторять те же ошибки. Перед закрытием попросите его записать краткую сводку в файл прогресса.

    1 мин чтения
  • Как сделать расширение для Chrome и Яндекс Браузера вайбкодингом?

    Попросите ИИ создать расширение на Manifest V3 (файлы manifest.json, popup.html и content.js), включите «Режим разработчика» на странице chrome://extensions и загрузите папку кнопкой «Загрузить распакованное».

    1 мин чтения
  • Как писать парсеры и скрипты автоматизации на Python вайбкодингом?

    Опишите ИИ источник данных, формат результата (CSV, Excel, Telegram) и попросите использовать виртуальное окружение venv. Для сайтов без сложного JS хватит requests + BeautifulSoup, для динамических страниц — Playwright.

    1 мин чтения
  • Как сделать так, чтобы сайт от ИИ не выглядел как «типовой шаблон»?

    Задайте ИИ конкретные дизайн-токены до написания кода: 1 акцентный цвет, 2 шрифта, шкалу отступов, стиль границ и запрет на шаблонные фиолетовые градиенты, лишние иконки и карточки со светящимися тенями.

  • Как подключить приём платежей (ЮKassa) к вайбкодинг-проекту?

    Зарегистрируйте магазин как самозанятый, ИП или ООО, создайте тестовый магазин в ЮKassa и попросите ИИ интегрировать API на бэкенде с обязательной проверкой статуса платежа через webhook и идемпотентностью.

  • Чек-лист безопасности вайбкодинг-приложения перед запуском в прод

    Перед открытием доступа пользователям проверьте 7 вещей: нет ли секретов в клиенте, включены ли проверки прав на сервере, валидируется ли ввод, настроены ли лимиты запросов, HTTPS, резервные копии базы и защита от XSS/SQL-инъекций.

    1 мин чтения
  • Как рефакторить большой проект с помощью ИИ и ничего не сломать?

    Никогда не просите ИИ «перепиши всё красиво за один раз». Выделите отдельную Git-ветку, покройте критичные функции тестами и дробите рефакторинг на мелкие шаги по одному модулю с проверкой сборки после каждого.

    1 мин чтения
  • Как сделать мини-игру в браузере вайбкодингом за один вечер?

    Начните с HTML5 Canvas на чистом JavaScript или Phaser (для 2D) / Three.js (для простого 3D). Сначала сделайте один работающий игровой цикл с примитивными фигурами, и только потом добавляйте графику, звук и таблицу рекордов.

    1 мин чтения
  • Терминальные ИИ-агенты (Claude Code, Qwen Code, Aider): как ими пользоваться?

    Терминальные агенты запускаются прямо в консоли внутри папки проекта: они сами читают файлы, правят код, запускают тесты и делают коммиты. Вы управляете ими обычным текстом и подтверждаете опасные команды.

  • Как настроить локальный вайбкодинг на своём ПК (Ollama + Continue)?

    Установите Ollama, скачайте специализированную модель для кода (например, Qwen2.5-Coder или Qwen3-Coder подходящего размера под вашу видеокарту) и подключите её в VS Code через бесплатное расширение Continue или Cline.

  • Как дать ИИ скриншот дизайна, чтобы он точно сверстал страницу?

    Снимайте отдельные секции (шапка, первый экран, карточки), а не длинную «простыню» всего сайта, прикладывайте скриншот в мультимодальную модель и обязательно дописывайте требования к адаптиву, шрифтам и состояниям кнопок.

    1 мин чтения
  • Как перенести проект из Bolt или Lovable к себе на компьютер?

    Подключите двухстороннюю синхронизацию с GitHub (или скачайте ZIP-архив), откройте папку в VS Code или Cursor, установите Node.js и запустите npm install, а затем npm run dev.

    1 мин чтения
  • Можно ли брать коммерческие заказы на вайбкодинг и какие есть риски?

    Да, для лендингов, прототипов, внутренних утилит и простых ботов это уже рабочий рынок. Главные риски — скрытые дыры в безопасности, невозможность поддержать код после усложнения и юридическая ответственность за ошибки.

    1 мин чтения
  • Как сделать Telegram Mini App вайбкодингом с нуля?

    Сделайте адаптивный веб-сайт с подключённым скриптом telegram-web-app.js, выложите его на HTTPS-домен и привяжите ссылку к боту через @BotFather. Обязательно проверяйте подпись initData на своём сервере, чтобы исключить подделку пользователя.

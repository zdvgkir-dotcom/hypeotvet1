Раздел 20

Разработка и сайты

Сайты, хостинг, домены и с чего начать в программировании. 30 вопросов.

  • Как сделать сайт бесплатно?

    Сгенерируйте сайт нейросетью или в конструкторе (Tilda, Taplink), а разместите бесплатно на GitHub Pages, Netlify или Cloudflare Pages.

  • Какой хостинг выбрать в России?

    Для статичных сайтов — бесплатные GitHub Pages/Netlify. Для сайтов на PHP/WordPress — Beget, Timeweb, REG.RU. Для своих приложений и ботов — VPS.

    1 мин чтения
  • С чего начать изучать программирование в 2026 году?

    Выберите направление (веб, боты, данные), начните с Python или JavaScript, учитесь на практике и используйте ИИ как наставника.

    Хайп1 мин чтения
  • Как купить домен и подключить к сайту?

    Купите домен у регистратора (REG.RU, RU-CENTER, Timeweb и др.), затем в DNS пропишите записи, которые даёт ваш хостинг.

    1 мин чтения
  • Чем фронтенд отличается от бэкенда?

    Фронтенд — то, что видит пользователь (интерфейс в браузере). Бэкенд — сервер, который хранит данные, проверяет логин и обрабатывает запросы.

  • Git и GitHub для новичка: 7 главных команд, которых хватит на старте

    Для 90% ежедневной работы достаточно 7 команд: git init (или clone), status, add, commit, push, pull и checkout -b. Git хранит историю изменений локально на компьютере, а GitHub — это облачный сервис для её синхронизации.

    Хайп1 мин чтения
  • За сколько можно выучить базу HTML и CSS с нуля?

    При занятиях по 1,5-2 часа в день уверенную базу HTML и CSS реально освоить за 3-4 недели. Этого хватит, чтобы сверстать аккуратный адаптивный лендинг, портфолио или править интерфейс в вайбкодинг-проектах.

    1 мин чтения
  • Адаптивная вёрстка на Flexbox и Grid: как сделать сайт красивым на телефоне?

    Используйте Flexbox для выравнивания элементов в одну линию (шапка, кнопки, меню) и CSS Grid для двумерных сеток карточек. Для мобильных добавьте тег viewport, подход Mobile First и перестроение колонок через auto-fit или медиазапросы.

    1 мин чтения
  • Что такое API, REST и JSON простыми словами?

    API — это «официант» с меню, через которого программы обмениваются данными. REST — популярный набор правил такого общения по HTTP-методам (GET, POST, PUT, DELETE), а JSON — простой текстовый формат, в котором передаются данные.

    1 мин чтения
  • Зачем нужен HTTPS и как получить бесплатный SSL-сертификат Let's Encrypt?

    HTTPS шифрует трафик между браузером и сервером, защищая пароли и данные форм от перехвата. Бесплатный сертификат Let's Encrypt автоматически выдаётся в один клик на большинстве хостингов или через утилиту Certbot на VPS.

    1 мин чтения
  • Базовое SEO сайта для Яндекса и Google: что настроить сразу после запуска?

    Пропишите уникальные теги title и description, один заголовок h1 на странице, создайте файлы robots.txt и sitemap.xml, добавьте сайт в Яндекс Вебмастер и Google Search Console и проверьте скорость на мобильных.

    1 мин чтения
  • Как ускорить загрузку сайта: PageSpeed, WebP и минификация

    В 80% случаев сайт тормозит из-за тяжёлых картинок и лишних скриптов. Переведите изображения в WebP/AVIF, задайте им ширину и loading="lazy", минифицируйте CSS/JS и включите сжатие Gzip или Brotli на сервере.

    1 мин чтения
  • Как сделать форму обратной связи на статичном сайте без бэкенда?

    Используйте сервисы приёма форм вроде Formspree, Web3Forms или Яндекс Форм, либо напишите маленький серверлес-обработчик (например, Яндекс Cloud Function), который безопасно перешлёт заявку в ваш Telegram.

    1 мин чтения
  • Базы данных SQL (PostgreSQL, SQLite) или NoSQL (MongoDB): что выбрать?

    Если сомневаетесь — выбирайте SQL (PostgreSQL для продакшена, SQLite для небольших проектов). SQL гарантирует строгую структуру и связи между таблицами, а NoSQL полезен, когда структура документов постоянно меняется или нужен быстрый кэш (Redis).

    1 мин чтения
  • Что такое Docker простыми словами и зачем разработчики используют его везде?

    Docker упаковывает ваш код вместе с нужной версией языка, библиотеками и настройками в изолированный «контейнер». Это навсегда решает проблему «у меня на компьютере работало, а на сервере сломалось».

  • На чём делать сайт в 2026: чистый HTML, Tilda, WordPress или Next.js?

    Выбирайте инструмент под цель: для быстрого лендинга под рекламу берите Tilda или чистый HTML, для блога и контента с админкой — WordPress, а для сложного интерактивного веб-сервиса и личного кабинета — Next.js или аналоги.

    1 мин чтения
  • Что такое Node.js и npm простыми словами?

    Node.js — это программа, которая позволяет запускать JavaScript вне браузера (на сервере или вашем ПК). А npm — встроенный «магазин библиотек» и менеджер команд, который устанавливает готовые пакеты в проект.

    1 мин чтения
  • Какой первый язык программирования выбрать: Python, JavaScript, Go или C#?

    Для веба и видимого результата в браузере берите JavaScript; для автоматизации, ботов, данных и ИИ — Python; для быстрых серверов — Go; для игр на Unity и корпоративного софта — C#. Главнее освоить базовую логику, чем идеально угадать первый язык.

  • Как подключить Яндекс Метрику на сайт и настроить цели?

    Создайте счётчик на metrika.yandex.ru, скопируйте выданный JS-код внутрь тега head (или body) на всех страницах сайта и добавьте цели на клик по кнопке или отправку формы, чтобы видеть реальные конверсии.

    1 мин чтения
  • Как защитить сайт от спама в формах и DDoS-атак?

    От спама в формах защищают скрытое поле-ловушка (honeypot), ограничение частоты запросов на сервере и невидимая капча (например, Yandex SmartCaptcha). От DDoS спасают обратный прокси/CDN с фильтрацией трафика и лимиты в Nginx.

  • Что такое CORS и почему браузер блокирует запросы к API?

    CORS — это защитный механизм браузера, который запрещает сайту на одном домене читать ответы от чужого домена без явного разрешения сервера. Ошибка чинится на стороне бэкенда добавлением заголовка Access-Control-Allow-Origin, а не во фронтенде.

    1 мин чтения
  • localStorage, cookies и sessionStorage: где правильно хранить данные в браузере?

    Используйте localStorage для несекретных настроек (тема, черновики), sessionStorage — для временных данных одной вкладки (шаги формы), а HttpOnly cookies — для токенов авторизации, чтобы до них не добрался чужой JS.

    1 мин чтения
  • Что такое TypeScript и стоит ли учить его сразу после JavaScript?

    TypeScript — это JavaScript со строгими типами данных, который находит опечатки и ошибки ещё в редакторе до запуска кода. Учить его стоит сразу после освоения базы JS (переменные, функции, массивы, async/await): сегодня это стандарт в веб-разработке.

  • Как устроен интернет: DNS, IP, сервер и браузер за 2 минуты

    Когда вы вводите адрес сайта, система DNS переводит понятное имя в числовой IP-адрес сервера. Браузер устанавливает защищённое соединение с этим сервером, скачивает HTML, CSS и JS и рисует из них страницу на экране.

  • Что такое CI/CD и как настроить автодеплой при пуше в GitHub?

    CI (непрерывная интеграция) автоматически проверяет код тестами и сборкой при каждом коммите, а CD (доставка) сама выкладывает обновлённую версию на сервер. Самый простой способ — бесплатный файл GitHub Actions в папке .github/workflows.

  • Как сделать тёмную и светлую тему на сайте на CSS-переменных?

    Вынесите все цвета в CSS-переменные внутри :root, переопределите их под атрибутом [data-theme="dark"] и переключайте этот атрибут на теге html через 10 строк JavaScript с сохранением выбора в localStorage.

    1 мин чтения
  • Основы доступности сайта (a11y): зачем она нужна и как её проверить?

    Доступность (a11y) делает сайт удобным для людей с нарушением зрения, моторики и тех, кто пользуется клавиатурой или читает с экрана на ярком солнце. Она одновременно улучшает UX, SEO и проверяется за 5 минут через Tab и Lighthouse.

    Оставьте в закреплённых 3-4 лучших завершённых проекта вместо десятка пустых черновиков. У каждого проекта должны быть живая ссылка (демо), понятный README.md со скриншотами, описанием стека и инструкцией запуска.

    Алгоритмы и синтаксис удобно тренировать на Codewars, LeetCode и Stepik, вёрстку — на Frontend Mentor, а главные навыки даёт создание 3-5 собственных пет-проектов, которыми пользуетесь вы сами.

  • Что такое PWA и как превратить сайт в приложение на телефоне?

    PWA (Progressive Web App) — это обычный сайт, который можно установить на рабочий экран телефона без App Store и Google Play. Для превращения сайта в PWA нужны HTTPS, файл manifest.json с иконками и скрипт Service Worker для кэширования.

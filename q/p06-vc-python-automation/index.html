Как писать парсеры и скрипты автоматизации на Python вайбкодингом?

Вайбкодинг бесплатно1 мин чтения
КороткоОпишите ИИ источник данных, формат результата (CSV, Excel, Telegram) и попросите использовать виртуальное окружение venv. Для сайтов без сложного JS хватит requests + BeautifulSoup, для динамических страниц — Playwright.

Что отлично автоматизируется за вечер

Сверка прайсов в Excel (openpyxl, pandas), переименование сотен файлов, сортировка PDF, уведомления в Telegram о новых заявках, сбор публичных цен и курсов валют.

Порядок запуска без хаоса на ПК

  1. Создайте папку и изолируйте зависимости: python -m venv .venv и активируйте окружение.
  2. Попросите ИИ сначала сделать прогон на 3-5 записях с сохранением результата в output.csv и подробными логами.
  3. Если сайт отдаёт данные через API (видно во вкладке Network в F12), парсите напрямую JSON — это в 10 раз быстрее и стабильнее HTML.
  4. Добавьте паузы между запросами (time.sleep), обработку таймаутов и повтор при ошибке.
Соблюдайте закон и правила площадок: не парсите закрытые разделы, чужие персональные данные (152-ФЗ), не обходите капчи и платный доступ, а также уважайте ограничения robots.txt и нагрузку на сервер.

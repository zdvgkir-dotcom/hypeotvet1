Что такое Telegram Mini Apps и как сделать свой первый WebApp?

ХайпНовоеБоты и серверы1 мин чтения
КороткоTelegram Mini Apps — это полноценные веб-приложения на HTML, CSS и JavaScript, которые открываются прямо внутри Telegram вместо кнопок бота. Для запуска нужен сайт с HTTPS и регистрация ссылки в BotFather.

Как устроен Telegram Mini App

Технически это обычная веб-страница, открытая во встроенном браузере Telegram. Подключив скрипт telegram-web-app.js, страница получает тему оформления, данные пользователя и кнопку отправки заказа обратно боту.

Шаги для первого запуска

  1. Сделайте одностраничный сайт (на чистом JS, React или Vue) и подключите https://telegram.org/js/telegram-web-app.js в <head>.
  2. Выложите проект на хостинг с обязательным HTTPS — подойдут Vercel, GitHub Pages, Cloudflare Pages или свой VPS с Nginx.
  3. Откройте @BotFather, выберите бота, затем Bot Settings -> Menu Button или команду /newapp и укажите URL.
  4. На сервере проверяйте подпись initData через HMAC-SHA256 по токену бота, чтобы нельзя было подделать ID пользователя.
Никогда не доверяйте initDataUnsafe на бэкенде: эти данные легко подменить в браузере. Всегда валидируйте хеш на сервере.

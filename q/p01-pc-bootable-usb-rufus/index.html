Как сделать загрузочную флешку Windows через Rufus или Ventoy?

Ноутбуки, ПК и железо1 мин чтения
КороткоВозьмите флешку от 8 ГБ и официальный ISO-образ Windows. Rufus создаст одну классическую установочную флешку (схема GPT для UEFI), а Ventoy позволяет просто копировать на флешку сразу несколько любых ISO-образов.

Вариант 1: через Rufus (классика для одной ОС)

  1. Скачайте официальный ISO-образ Windows (с сайта Microsoft) и бесплатную утилиту Rufus с rufus.ie.
  2. Подключите флешку на 8 ГБ и выше (все данные с неё будут стёрты!).
  3. В Rufus выберите вашу флешку, нажмите Выбрать и укажите ISO-файл.
  4. Для всех современных ПК оставьте схему раздела GPT и целевую систему UEFI (non CSM). Для очень старых ПК без UEFI выберите MBR.
  5. Нажмите Старт и дождитесь надписи «Готов» (обычно 3–7 минут).

Вариант 2: через Ventoy (мультизагрузочная флешка)

  • Устанавливаете Ventoy на флешку один раз — дальше просто перетаскиваете на неё обычные файлы .iso (Windows 10, Windows 11, Ubuntu, реаниматор) как на обычный диск.
  • При загрузке с флешки появляется удобное меню выбора нужного образа. На флешке при этом можно хранить обычные папки с драйверами.
Скачивайте ISO-образы ОС и утилиты только с официальных источников — в «сборках с торрентов» нередко вшиты скрытые майнеры и стилеры паролей.

Как сделать форму обратной связи на статичном сайте без бэкенда?

Разработка и сайты1 мин чтения
КороткоИспользуйте сервисы приёма форм вроде Formspree, Web3Forms или Яндекс Форм, либо напишите маленький серверлес-обработчик (например, Яндекс Cloud Function), который безопасно перешлёт заявку в ваш Telegram.

3 рабочих способа

СпособПлюсыНюансы
Яндекс Формы (iframe)Бесплатно, работает в РФ, хранит ответы в таблицеОграниченная кастомизация дизайна
Formspree / Web3FormsСвой красивый HTML, настройка за 2 минутыЛимиты на бесплатном тарифе, данные на зарубежных серверах
Cloud Function → TelegramПолный контроль, заявки мгновенно в TelegramНужно 20 строк кода на Node.js/Python

Чего делать точно нельзя

Не отправляйте заявки напрямую из браузерного JS в Telegram Bot API с вшитым токеном бота — токен сразу украдут из исходного кода страницы и используют для спама. Секрет должен лежать на стороне облачной функции или сервиса форм.

Если форма собирает имя, телефон или e-mail жителей РФ, разместите рядом чекбокс согласия на обработку персональных данных и ссылку на политику конфиденциальности (152-ФЗ).

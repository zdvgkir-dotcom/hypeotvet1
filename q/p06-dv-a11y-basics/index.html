Основы доступности сайта (a11y): зачем она нужна и как её проверить?

НовоеРазработка и сайты1 мин чтения
КороткоДоступность (a11y) делает сайт удобным для людей с нарушением зрения, моторики и тех, кто пользуется клавиатурой или читает с экрана на ярком солнце. Она одновременно улучшает UX, SEO и проверяется за 5 минут через Tab и Lighthouse.

5 базовых правил, которые закрывают 80% проблем

  1. Настоящие теги: для действий используйте <button>, для переходов — <a href="...">, а не кликабельные <div>.
  2. Фокус с клавиатуры: не убирайте обводку через outline: none без замены — используйте аккуратный :focus-visible.
  3. Контраст текста: соотношение контрастности обычного текста к фону должно быть не ниже 4.5:1 (стандарт WCAG AA).
  4. Подписи к полям и иконкам: связывайте каждый <input> с <label>, а кнопкам только с иконкой (например, крестику закрытия) добавляйте aria-label="Закрыть окно".
  5. Атрибут alt: осмысленное описание для информативных фото и пустой alt="" для чистого декора.

Быстрая проверка

Уберите руку с мыши и попробуйте пройти весь сайт клавишами Tab, Shift+Tab, Enter и Esc, затем запустите вкладку Lighthouse → Accessibility в Chrome DevTools.

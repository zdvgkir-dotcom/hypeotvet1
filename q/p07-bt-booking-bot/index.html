Как устроен бот для записи клиентов в салон или к мастеру?

Боты и серверы1 мин чтения
КороткоБот для записи состоит из каталога услуг, выбора мастера и свободного слота, сохранения брони в БД и автоматических напоминаний за 24 и 2 часа до визита.

Обязательные сценарии бота записи

  1. Выбор услуги с ценой и длительностью (например, стрижка — 60 минут).
  2. Выбор мастера, даты и только свободных временных слотов.
  3. Запрос имени и телефона (через кнопку request_contact) плюс согласие на обработку персональных данных по 152-ФЗ.
  4. Уведомление администратору, возможность отменить или перенести визит и автонапоминание клиенту.

Практичный стек

  • Быстрый старт без кода: интеграция YCLIENTS или DIKIDI с готовым Telegram-ботом — не придётся писать логику пересечения слотов с нуля.
  • Своя разработка: Python + aiogram 3 + PostgreSQL + APScheduler для напоминаний + Google Calendar API для синхронизации графика мастера.
Защита от двойной записи обязательна: проверяйте занятость слота внутри транзакции базы данных в момент подтверждения.

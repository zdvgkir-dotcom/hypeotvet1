Как понять, какая нейросеть реально лучше: рейтинги и бенчмарки

Нейросети без VPN1 мин чтения
КороткоНе верьте только рекламным графикам компаний: смотрите слепые сравнения пользователей на LMArena (Chatbot Arena) и профильные тесты по коду, математике и русскому языку, а главное — тестируйте на 5–10 своих задачах.

При каждом релизе разработчики показывают графики, где их модель «побила всех». Проблема в том, что часть классических тестов модели уже «зазубрили» на этапе обучения (data contamination).

На какие рейтинги действительно стоит смотреть

  • LMArena (бывш. Chatbot Arena) — пользователи вслепую сравнивают ответы двух анонимных моделей на один запрос и голосуют. Есть отдельные таблицы для кода, веба и картинок.
  • SWE-bench Verified / LiveCodeBench — реальные задачи программирования из GitHub и свежие олимпиадные задачи, которых не было в старых датасетах.
  • Artificial Analysis — удобные графики соотношения «качество / цена API / скорость генерации токенов в секунду».
Лучший бенчмарк — ваш личный набор из 5 типовых рабочих запросов на русском языке. Модель с 4-го места в мировом рейтинге нередко пишет естественнее на русском, чем лидер английских тестов.

Какие инструменты для вайбкодинга можно использовать бесплатно?

ХайпВайбкодинг бесплатно1 мин чтения
КороткоБесплатно: Trae, Qwen Code, VS Code + Cline/Continue с бесплатными моделями, а также пробные тарифы Cursor, Windsurf, Bolt и Lovable.

Редакторы кода с ИИ

ИнструментБесплатноДля кого
TraeЕсть бесплатный тарифНовички — похож на VS Code, есть агент-режим
CursorОграниченный бесплатный планСамый популярный AI-редактор
WindsurfБесплатный планАльтернатива Cursor
VS Code + Cline / Continue / Kilo CodeРасширения бесплатны, платите только за модель (или берёте бесплатную)Кто хочет гибкость
Qwen CodeБесплатный лимит запросовАгент в терминале

Конструкторы в браузере (ничего не надо ставить)

  • Bolt.new, Lovable, v0 — пишете идею, получаете готовое веб-приложение. На бесплатном тарифе — ограниченное число сообщений в день.

Бесплатные модели для расширений

Через OpenRouter доступны бесплатные версии некоторых моделей (DeepSeek, Qwen и др.). API DeepSeek платный, но очень дешёвый — сотни запросов стоят копейки.

Доступность сервисов в России меняется быстро. Перед тем как платить или переносить работу — проверьте, что сервис открывается у вас прямо сейчас.

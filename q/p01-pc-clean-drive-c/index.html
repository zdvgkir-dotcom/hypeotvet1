Как освободить место на диске C в Windows без сторонних программ?

ХайпНоутбуки, ПК и железо1 мин чтения
КороткоЗапустите встроенную «Очистку диска» от имени администратора (удалит старые обновления Windows), включите «Контроль памяти» и проверьте папки «Загрузки» и Temp. Чистильщики реестра не нужны.

4 безопасных встроенных способа

  1. Очистка системных файлов. Нажмите Win + R, введите cleanmgr → выберите диск C → нажмите Очистить системные файлы. Отметьте «Очистка обновлений Windows», «Временные файлы» и «Предыдущие установки Windows» (Windows.old может занимать 15–25 ГБ).
  2. Контроль памяти. Откройте Параметры → Система → Память → Временные файлы и удалите кэш доставок, эскизы и содержимое Корзины.
  3. Ручная чистка папки Temp. Нажмите Win + R, введите %temp% → выделите всё (Ctrl + A) и удалите. Файлы, занятые системой, просто пропустите.
  4. Поиск «пожирателей» места. В разделе Память → Установленные приложения отсортируйте программы по размеру. Также проверьте папки Загрузки и кэш Telegram/Discord (в Telegram: Настройки → Продвинутые → Управление памятью).
Не удаляйте вручную файлы в папках C:\Windows и ProgramData, а также избегайте агрессивных «оптимизаторов реестра» — они освобождают килобайты, но нередко ломают систему.

Какие ограничения и лимиты есть у Telegram Bot API?

Боты и серверы1 мин чтения
КороткоБот может отправлять до 30 сообщений в секунду разным юзерам, до 1 сообщения в секунду в один чат, текст до 4096 символов и файлы до 50 МБ через стандартный API.

Основные технические лимиты

ПараметрСтандартный Bot APIПримечание
Рассылка разным чатам~30 сообщений/секПревышение даёт ошибку 429
Один личный чат1 сообщение/секКороткие всплески допускаются
Группа или канал20 сообщений/минУчитываются правки и медиа
Длина текста / подписи4096 / 1024 символаДля фото и видео действует лимит подписи
Загрузка / скачивание файла50 МБ / 20 МБЧерез Local Bot API Server — до 2000 МБ
Если бот работает с тяжёлыми видео или архивами, поднимите официальный Local Bot API Server на своём VPS — это снимает ограничение 20/50 МБ до 2 ГБ.

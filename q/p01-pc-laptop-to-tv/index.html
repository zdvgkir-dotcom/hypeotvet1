Как подключить ноутбук к телевизору по кабелю или без проводов?

Ноутбуки, ПК и железо1 мин чтения
КороткоСамый надёжный способ — кабель HDMI (или USB-C → HDMI), без задержек и потери качества. Для фильмов и презентаций без проводов на Windows нажмите Win + K и выберите Smart TV по Miracast.

Способ 1: по кабелю HDMI (лучше для игр и 4K)

  1. Соедините ноутбук и телевизор кабелем HDMI (для 4K 60 Гц нужен кабель стандарта HDMI 2.0 и выше; если на ноутбуке только USB-C с поддержкой DisplayPort Alt Mode — используйте адаптер USB-C → HDMI).
  2. На пульте телевизора нажмите кнопку Source / Input и выберите нужный вход HDMI.
  3. На ноутбуке нажмите Win + P и выберите Расширить (удобнее для фильмов на ТВ) или Только второй экран.
  4. Если звук остался в ноутбуке — кликните по значку динамика в трее Windows и переключите вывод звука на модель телевизора (HDMI Audio).

Способ 2: без проводов (Wi-Fi / Miracast)

  • Подключите ноутбук и Smart TV к одному Wi-Fi роутеру.
  • На Windows нажмите Win + K (трансляция) и выберите телевизор из списка. На macOS используйте AirPlay из Пункта управления (если ТВ поддерживает AirPlay 2).
  • Беспроводной режим даёт заметную задержку курсора — он подходит для видео и слайдов, но не для динамичных игр.

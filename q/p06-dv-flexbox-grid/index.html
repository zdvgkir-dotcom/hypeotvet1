Адаптивная вёрстка на Flexbox и Grid: как сделать сайт красивым на телефоне?

Разработка и сайты1 мин чтения
КороткоИспользуйте Flexbox для выравнивания элементов в одну линию (шапка, кнопки, меню) и CSS Grid для двумерных сеток карточек. Для мобильных добавьте тег viewport, подход Mobile First и перестроение колонок через auto-fit или медиазапросы.

Когда брать Flexbox, а когда Grid

  • Flexbox (display: flex) — идеален для одной оси: распределить логотип и меню по краям (justify-content: space-between) или отцентрировать иконку с текстом (align-items: center).
  • CSS Grid (display: grid) — идеален для сеток товаров, статей и сложных макетов со строками и колонками.

4 правила адаптива без боли

  1. Обязательно добавьте в <head>: <meta name="viewport" content="width=device-width, initial-scale=1.0">.
  2. Запретите картинкам вылезать за экран: img { max-width: 100%; height: auto; }.
  3. Используйте «резиновую» сетку без лишних медиазапросов: grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); — карточки сами перенесутся в 1, 2 или 3 колонки.
  4. Проверяйте сайт в DevTools в режиме телефона на ширине 360px и 390px: следите, чтобы не появлялась горизонтальная прокрутка.

Что такое Node.js и npm простыми словами?

Разработка и сайты1 мин чтения
КороткоNode.js — это программа, которая позволяет запускать JavaScript вне браузера (на сервере или вашем ПК). А npm — встроенный «магазин библиотек» и менеджер команд, который устанавливает готовые пакеты в проект.

Зачем понадобился Node.js

Изначально JavaScript работал только внутри браузера. Node.js вынес движок Chrome V8 в систему: теперь на одном и том же языке можно писать и сайт, и бэкенд, и Telegram-ботов, и сборщики проектов вроде Vite.

Как устроен npm

  • package.json — паспорт проекта: список нужных библиотек и коротких скриптов (npm run dev, npm run build).
  • package-lock.json — точные версии всех зависимостей, чтобы у каждого участника установился одинаковый набор.
  • node_modules/ — папка со скачанными библиотеками. Она весит сотни мегабайт, поэтому её всегда добавляют в .gitignore и восстанавливают командой npm install.
Проверяйте названия пакетов перед установкой: злоумышленники иногда создают поддельные пакеты с опечаткой в имени (тайпосквоттинг).

Как перенести Windows с HDD на новый SSD без переустановки?

Ноутбуки, ПК и железо1 мин чтения
КороткоПодключите новый SSD к ПК, запустите программу клонирования (Macrium Reflect, Hasleo Disk Clone или фирменную утилиту производителя SSD) и скопируйте системный диск целиком. Затем в BIOS выберите загрузку с нового SSD.

Пошаговый перенос системы

  1. Подготовка. Убедитесь, что объём занятых данных на старом диске меньше полного объёма нового SSD (лучше с запасом 20–30 ГБ). Удалите лишние игры и фильмы со старого диска, чтобы ускорить копирование.
  2. Подключение. Установите новый SSD в свободный слот M.2/SATA внутри ПК или подключите к ноутбуку через внешний USB-бокс для SSD.
  3. Клонирование. Используйте бесплатную Hasleo Disk Clone (режим System Clone), триал Macrium Reflect или фирменную утилиту вашего SSD (например, Samsung Data Migration в Samsung Magician или Acronis for Crucial/WD/Kingston). Обязательно переносите все скрытые системные разделы (EFI, раздел восстановления), а не только диск C.
  4. Первый запуск. Выключите ПК, физически отключите старый HDD (или поменяйте приоритет загрузки в BIOS на новый SSD) и загрузите Windows.
Только убедившись, что система стабильно стартует с нового SSD без старого диска, можно подключить старый HDD обратно и отформатировать его под хранение файлов.

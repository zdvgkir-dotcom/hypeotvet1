За сколько можно выучить базу HTML и CSS с нуля?

Разработка и сайты1 мин чтения
КороткоПри занятиях по 1,5-2 часа в день уверенную базу HTML и CSS реально освоить за 3-4 недели. Этого хватит, чтобы сверстать аккуратный адаптивный лендинг, портфолио или править интерфейс в вайбкодинг-проектах.

Реалистичный план на 4 недели

  1. Неделя 1 — HTML и семантика: структура документа, заголовки h1-h6, ссылки, списки, изображения, формы и семантические теги (header, main, section, footer).
  2. Неделя 2 — основы CSS и блочная модель: селекторы, цвета, шрифты, box-sizing: border-box, разница между margin и padding, позиционирование.
  3. Неделя 3 — раскладка и адаптив: Flexbox, CSS Grid, медиазапросы @media, относительные единицы (rem, %, vw).
  4. Неделя 4 — практика: сверстайте 2-3 реальных макета с мобильной версией и выложите их на GitHub Pages.

Главная ошибка новичков

Не зубрите все 300 CSS-свойств подряд и не смотрите 10-часовые курсы без набора кода. Достаточно 20% теории и 80% практики: пробуйте повторить карточки, меню и формы с любимых сайтов, подглядывая в DevTools (F12).

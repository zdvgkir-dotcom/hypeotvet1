Что делать, если случайно выложил токен бота на GitHub?

Боты и серверы1 мин чтения
КороткоНемедленно перевыпустите токен в @BotFather командой /revoke — одного удаления коммита недостаточно, так как боты-сканеры перехватывают ключи из публичных репозиториев за секунды.

Экстренные действия за 2 минуты

  1. Откройте @BotFather -> /mybots -> выберите бота -> API Token -> Revoke current token. Старый ключ мгновенно перестанет работать.
  2. Обновите новый токен в .env на сервере и перезапустите бота.
  3. Проверьте, не попали ли в тот же коммит пароли от БД, ключи OpenAI или ЮKassa — их тоже нужно немедленно перевыпустить.
  4. Очистите историю Git (например, через git-filter-repo) и добавьте .env в .gitignore.
Чтобы избежать повторения, храните секреты только в переменных окружения, а в репозиторий кладите шаблон .env.example без реальных значений.

Как сделать Telegram-бота с нейросетью внутри?

ХайпБоты и серверы1 мин чтения
КороткоПодключите к боту API нейросети (DeepSeek, GigaChat, YandexGPT). Бот пересылает сообщение пользователя в API и отвечает текстом модели.

Схема

Пользователь → ваш бот → API нейросети → ответ → пользователь.

Какие API доступны из России

  • DeepSeek API — очень дешёвый, совместим с форматом OpenAI.
  • GigaChat API — есть бесплатный лимит для физлиц.
  • YandexGPT в Yandex Cloud — оплата российской картой, стартовый грант для новых аккаунтов.

Пример на DeepSeek

from openai import OpenAI
client = OpenAI(api_key="КЛЮЧ", base_url="https://api.deepseek.com")

def ask(text):
    r = client.chat.completions.create(
        model="deepseek-chat",
        messages=[{"role": "user", "content": text}],
    )
    return r.choices[0].message.content

Вызовите ask(message.text) в обработчике aiogram — и бот с ИИ готов. Ключи храните в .env, а не в коде.

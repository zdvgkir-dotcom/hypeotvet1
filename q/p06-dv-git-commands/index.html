Git и GitHub для новичка: 7 главных команд, которых хватит на старте

ХайпРазработка и сайты1 мин чтения
КороткоДля 90% ежедневной работы достаточно 7 команд: git init (или clone), status, add, commit, push, pull и checkout -b. Git хранит историю изменений локально на компьютере, а GitHub — это облачный сервис для её синхронизации.

В чём разница между Git и GitHub

Git — программа на вашем компьютере, которая запоминает снимки (коммиты) проекта. GitHub (или российский GitFlic) — сайт, куда вы загружаете эти снимки для бэкапа и командной работы.

7 базовых команд

КомандаЧто делает
git init / git clone URLСоздаёт репозиторий в папке или скачивает готовый с GitHub
git statusПоказывает, какие файлы изменены прямо сейчас
git add .Добавляет изменённые файлы в подготовку к сохранению
git commit -m "текст"Фиксирует снимок изменений в локальной истории
git pushОтправляет локальные коммиты на GitHub
git pullЗабирает свежие изменения с GitHub на компьютер
git checkout -b feat/uiСоздаёт новую ветку для экспериментов, не трогая main
Перед первым коммитом один раз задайте имя и почту: git config --global user.name "Имя" и user.email "mail@example.com".

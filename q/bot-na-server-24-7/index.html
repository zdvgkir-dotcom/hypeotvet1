Как запустить бота на сервере, чтобы он работал 24/7?

НовоеБоты и серверы1 мин чтения
КороткоАрендуйте VPS, загрузите код, установите зависимости и запустите бота как службу systemd (или в Docker), чтобы он перезапускался сам.
  1. Подключитесь к серверу: ssh root@IP_СЕРВЕРА
  2. Установите Python: apt update && apt install -y python3-venv git
  3. Загрузите код: git clone ссылка_на_репозиторий bot && cd bot
  4. Окружение: python3 -m venv venv && venv/bin/pip install -r requirements.txt
  5. Создайте службу /etc/systemd/system/bot.service:
[Unit]
Description=Telegram bot
After=network.target

[Service]
WorkingDirectory=/root/bot
ExecStart=/root/bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target

Запуск: systemctl enable --now bot. Логи: journalctl -u bot -f.

Не хотите разбираться — дайте эту инструкцию нейросети вместе с вашим кодом, она подскажет команды под ваш случай.

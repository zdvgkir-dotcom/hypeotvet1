Как сделать мобильное приложение вайбкодингом: PWA, Capacitor или React Native?

ХайпВайбкодинг бесплатно1 мин чтения
КороткоДля быстрого запуска без модерации сторов делайте PWA. Если нужен файл для RuStore, Google Play или App Store из готового веб-проекта — оберните его в Capacitor. Для сложной анимации и нативного UI берите React Native (Expo).

Сравнение трёх путей

ПодходСложность с ИИПубликацияДоступ к железу
PWAМинимальнаяПо ссылке, «На экран Домой»Ограниченный
CapacitorНизкая (ваш HTML/React)RuStore, Google Play, App StoreКамера, пуши, GPS через плагины
React Native + ExpoСредняяВсе сторы + тест в Expo GoПочти полный нативный

Что выбрать новичку

  • Начните с PWA, если проверяете гипотезу: работает сразу на Android и iOS, не нужен Mac и платные аккаунты разработчика.
  • Берите Expo (React Native), если с первого дня нужен нативный интерфейс: ИИ отлично пишет код на Expo, а тестировать его можно на телефоне по QR-коду через приложение Expo Go.
  • Для сборки под iOS и публикации в App Store потребуется macOS (или облачная сборка EAS Build) и платный аккаунт Apple Developer.
Для российской аудитории на Android учитывайте публикацию в RuStore — туда можно выгружать APK/AAB, собранный через Capacitor или Expo.

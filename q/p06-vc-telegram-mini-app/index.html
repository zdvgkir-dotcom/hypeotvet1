Как сделать Telegram Mini App вайбкодингом с нуля?

ХайпНовоеВайбкодинг бесплатно1 мин чтения
КороткоСделайте адаптивный веб-сайт с подключённым скриптом telegram-web-app.js, выложите его на HTTPS-домен и привяжите ссылку к боту через @BotFather. Обязательно проверяйте подпись initData на своём сервере, чтобы исключить подделку пользователя.

Как устроен Telegram Mini App

Технически это обычный мобильный сайт (HTML/CSS/JS или React), который открывается внутри окна Telegram и общается с мессенджером через официальный SDK.

Запуск за 5 шагов

  1. Создайте бота: в @BotFather выполните /newbot и сохраните токен в .env.
  2. Соберите веб-интерфейс: подключите в <head> скрипт https://telegram.org/js/telegram-web-app.js. Попросите ИИ вызывать Telegram.WebApp.ready(), expand() и брать цвета из themeParams, чтобы приложение подстраивалось под тему Telegram.
  3. Выложите на HTTPS: Telegram открывает Mini App только по защищённому протоколу HTTPS (подойдут GitHub Pages для статики или VPS/Amvera с SSL для бэкенда).
  4. Привяжите URL: в @BotFather через /newapp или настройку кнопки меню (Menu Button) укажите ваш HTTPS-адрес.
  5. Защитите бэкенд: проверяйте криптографическую подпись строки initData с помощью токена бота на сервере — не доверяйте user.id, присланному просто из браузера.
Для цифровых товаров внутри Telegram изучите официальные правила монетизации (Telegram Stars) — они регулярно обновляются.

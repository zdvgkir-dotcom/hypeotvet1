Зачем нужен Docker Compose для запуска бота и базы данных?

Боты и серверы1 мин чтения
КороткоDocker Compose описывает бота, базу данных, Redis и переменные окружения в одном файле docker-compose.yml и поднимает весь проект одной командой без конфликтов версий Python и библиотек.

Главные плюсы Docker Compose

  • Одинаковое окружение на вашем ноутбуке и на сервере: исчезает проблема «у меня локально работало».
  • Бот, PostgreSQL и Redis общаются внутри изолированной сети по именам сервисов, без открытия лишних портов наружу.
  • Параметр restart: unless-stopped автоматически перезапустит бот после сбоя или перезагрузки VPS.

Что важно не забыть в конфиге

  1. Подключите volumes для папки данных PostgreSQL (/var/lib/postgresql/data), иначе база очистится при пересоздании контейнера.
  2. Вынесите токены и пароли в отдельный файл .env и добавьте его в .gitignore.
  3. Ограничьте размер логов через logging (max-size: 10m, max-file: 3), чтобы логи не забили весь диск VPS.

Как настроить автоматические бэкапы VPS и базы данных?

Боты и серверы1 мин чтения
КороткоНастройте ежедневный дамп базы данных через cron и отправку зашифрованного архива в внешнее хранилище (S3, Яндекс Диск или второй сервер) по правилу 3-2-1.

Правило надёжного резервного копирования

Бэкап, который лежит на том же диске VPS, не спасает от поломки диска, взлома или случайного удаления сервера. Всегда выгружайте копии наружу.

Простая рабочая схема

  1. Для PostgreSQL снимайте дамп командой pg_dump -Fc dbname > backup_$(date +%F).dump, для SQLite — через sqlite3 bot.db ".backup backup.db" (простое копирование cp может повредить открытую базу).
  2. Отправляйте архив в облако (Yandex Object Storage, Selectel S3, Backblaze) с помощью rclone или restic с шифрованием.
  3. Добавьте скрипт в crontab -e на 03:00 ночи и удаляйте локальные файлы старше 7 дней.
  4. Раз в месяц пробуйте реально восстановить базу на тестовом окружении — непроверенный бэкап часто оказывается пустым.

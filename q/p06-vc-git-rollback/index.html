Как работать с Git в вайбкодинге и откатывать неудачные правки ИИ?

Вайбкодинг бесплатно1 мин чтения
КороткоДелайте коммит перед каждым крупным запросом к ИИ. Если агент сломал проект, одной командой git checkout -- . или git reset --hard HEAD вы мгновенно вернётесь к последней рабочей версии.

Почему нельзя полагаться только на Ctrl+Z

ИИ-агент часто правит 5-10 файлов одновременно. Если результат вас не устроил, отменять правки вручную по файлам долго и легко оставить поломанный код. Git работает как система сохранений в игре.

Базовый ритм вайбкодера

  1. Перед новой фичей создайте ветку: git checkout -b feat/search.
  2. После каждого удачного шага сохраните состояние: git add . и git commit -m "добавлен поиск".
  3. Посмотрите, что именно поменял ИИ: git diff или вкладка Source Control в редакторе.

Команды быстрого спасения

  • Отменить все несохранённые правки ИИ: git restore . (удалить и новые неотслеживаемые файлы: git clean -fd).
  • Откатить последний неудачный коммит, сохранив файлы: git reset --soft HEAD~1.
  • Полностью вернуться к прошлому коммиту: git reset --hard HEAD~1.
Команда git reset --hard безвозвратно удаляет несохранённые изменения. Используйте её, только если точно уверены, что текущий вариант не нужен.

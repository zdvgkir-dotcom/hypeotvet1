Как перенести проект из Bolt или Lovable к себе на компьютер?

Вайбкодинг бесплатно1 мин чтения
КороткоПодключите двухстороннюю синхронизацию с GitHub (или скачайте ZIP-архив), откройте папку в VS Code или Cursor, установите Node.js и запустите npm install, а затем npm run dev.

Зачем переносить проект из браузерного конструктора

В браузерных средах вроде Bolt.new, Lovable или v0 удобно делать первый прототип, но на своём ПК вы получаете полный контроль над Git, не сжигаете кредиты на мелкие правки и можете деплоить код на любой российский сервер.

Пошаговый перенос

  1. Экспорт кода: в Lovable нажмите GitHub → Connect (лучший вариант, сохраняет историю), в Bolt выберите Export → Download Project или синхронизацию с GitHub.
  2. Клонирование: выполните git clone <ссылка_на_репозиторий> и откройте папку в Cursor или VS Code.
  3. Окружение: установите Node.js LTS (версии 20 или 22) с официального сайта.
  4. Переменные: скопируйте ключи (например, URL и anon key от Supabase) в локальный файл .env.
  5. Запуск: в терминале редактора выполните npm install, а затем npm run dev и откройте адрес вроде http://localhost:5173.
Если при сборке мешают специфичные плагины платформы-конструктора в vite.config.ts, попросите ИИ в локальном редакторе аккуратно вычистить зависимости конструктора.

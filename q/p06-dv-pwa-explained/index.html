Что такое PWA и как превратить сайт в приложение на телефоне?

НовоеРазработка и сайты1 мин чтения
КороткоPWA (Progressive Web App) — это обычный сайт, который можно установить на рабочий экран телефона без App Store и Google Play. Для превращения сайта в PWA нужны HTTPS, файл manifest.json с иконками и скрипт Service Worker для кэширования.

Что умеет PWA

После нажатия «На экран Домой» сайт открывается на весь экран без адресной строки браузера, имеет свою иконку, запускается почти мгновенно и может работать даже без интернета (показывая закэшированные страницы).

3 обязательных компонента

  1. HTTPS: без защищённого соединения браузер не разрешит установку (кроме localhost при разработке).
  2. Файл manifest.json: подключается в <head>, содержит название приложения, иконки 192x192 и 512x512, цвет темы и режим "display": "standalone".
  3. Service Worker (sw.js): фоновый скрипт, который сохраняет статические файлы в кэш браузера и отдаёт их при пропадании сети.

Плюсы и ограничения

  • Одна кодовая база для всех устройств, мгновенные обновления без модерации магазинов приложений.
  • На iOS ограничения жёстче, чем на Android: установка возможна только через Safari («Поделиться → На экран Домой»), а доступ к части датчиков и фоновой работе ограничен.

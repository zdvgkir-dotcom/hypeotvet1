Как создать Telegram-бота бесплатно?

ХайпБоты и серверы1 мин чтения
КороткоПолучите токен у @BotFather, напишите бота на Python (библиотека aiogram) с помощью нейросети и запустите у себя или на сервере.

Шаг 1. Токен

В Telegram найдите @BotFather → /newbot → придумайте имя и username. Сохраните токен — это «пароль» бота.

Шаг 2. Код

Установите Python и библиотеку: pip install aiogram. Минимальный бот-эхо:

import asyncio
from aiogram import Bot, Dispatcher
from aiogram.types import Message

bot = Bot("ВАШ_ТОКЕН")
dp = Dispatcher()

@dp.message()
async def echo(message: Message):
    await message.answer(f"Вы написали: {message.text}")

asyncio.run(dp.start_polling(bot))

Шаг 3. Запуск

Запустите python bot.py — бот работает, пока включён компьютер. Чтобы он работал 24/7, разместите его на VPS (см. вопрос про сервер).

Без кода

Есть конструкторы ботов (например, BotHelp, Salebot, PuzzleBot) — подходят для воронок и рассылок.
